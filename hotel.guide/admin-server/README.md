# 아르반호텔 관리자 연결 준비본

현재 온라인 배포 전입니다. 호텔 계정과 로그인 정책 설정 없이는 서버 편집을 허용하지 않습니다.
기존 GitHub Pages 가이드북은 그대로 유지됩니다. connection-config.js의 publicApi가 빈 값이면 기존 data.js를 사용합니다.

## 구성
- Workers: 관리자 화면과 API
- Cloudflare Access: 허용된 호텔 담당자 이메일로 로그인
- R2 비공개 버킷: 장소 JSON, 사진, 직전 게시 내용의 버전별 백업
- 손님 의견을 수집하는 API는 없습니다. 이 저장소는 호텔이 편집하는 장소 정보와 사진만 저장합니다.
- AI 기능 연결은 이 작업에 포함되지 않습니다.

## 계정 준비 후 개발 담당자가 할 일
1. 호텔 소유 Cloudflare 계정에 로그인합니다. R2/Access 사용 조건과 요금을 확인하고 선택합니다. 앞서 안내한 Workers 기본료만으로 모든 기능이 무조건 포함되는 것은 아닙니다.
2. 비공개 R2 버킷 arban-guide-content를 만듭니다. 버킷 전체 공개는 켜지 않습니다.
3. wrangler.jsonc의 ACCESS_TEAM_DOMAIN, ACCESS_AUD, ADMIN_EMAILS를 실제 값으로 채웁니다. 이메일은 쉼표로 구분합니다. GUIDE_URL이 변경되면 build.mjs의 초기 이미지 기준 주소도 변경합니다.
4. Cloudflare Access self-hosted 앱에서 관리자 호스트의 /, /admin.html, /admin.css, /admin.js, /admin-bootstrap.js, /data.js, /connection-config.js, /api/admin/*를 보호하고 지정한 호텔 이메일만 허용합니다. /api/places와 /media/*는 손님용 공개 경로이므로 로그인 보호 대상에서 제외합니다. Worker 자체도 JWT 서명·발급자·대상·만료와 허용 이메일을 검증합니다. workers.dev와 사용자 지정 도메인 우회도 확인합니다.
5. 이 폴더에서 npm install, npm test, npm run deploy를 실행합니다. 최초 배포 전에는 테스트용 주소/버킷으로 검증합니다. 비밀 키를 코드에 넣지 않습니다.
6. 배포 주소 /admin.html에 호텔 계정으로 로그인합니다. 최초 장소 데이터는 build 때 data.js에서 만들어집니다.
7. 손님용 connection-config.js의 publicApi를 https://배포호스트/api/places로 입력합니다.
8. GitHub에 index.html, app.js, connection-config.js, guide-content.js를 올립니다. 나머지 기존 자산은 유지합니다. admin-server 폴더는 GitHub Pages에 올릴 필요가 없습니다.

## 호텔 담당자 사용
- 장소 선택 → 정보/사진 변경 → 브라우저에 초안 저장 → 미리보기 → 사이트에 반영
- 브라우저 저장은 온라인 반영이 아닙니다. 온라인 모드 재접속 시 서버의 최신본을 불러옵니다. 로컬 저장은 기기별이므로 중요한 작업은 수정본 파일도 내려받습니다.
- 사이트에 반영은 저장된 전체 목록에 적용됩니다. 숨김과 삭제도 함께 반영됩니다.
- 동시 수정 충돌 시 덮어쓰지 않고 중단합니다. 수정본을 내려받고 새로고침해서 비교합니다.
- 새 사진은 파일당 2MB 이하, 한 번 게시 요청은 전체 24MB 이하입니다. 많은 사진은 여러 번 나눠 반영합니다.
- 게시 전 원본은 R2 history/에 보관됩니다. 복구는 개발 담당자가 백업을 검사한 뒤 수행합니다. 삭제된 사진은 자동 영구 삭제하지 않으므로 주기적인 저장 용량 점검이 필요합니다.
- 손님 페이지를 새로고침하면 최신본을 불러옵니다. 통신 실패 시 장소 목록을 비우고 재시도 안내를 표시합니다. 숨김·삭제한 장소가 오래된 기본본으로 다시 나타나지 않도록 처리합니다.

## 배포 후 반드시 확인
비로그인/다른 이메일의 관리자 및 쓰기 요청 거부, 호텔 로그인, 변경 게시, 실제 휴대폰 사진 표시, 숨김·삭제, 두 담당자 동시 게시 충돌, 서버 장애 안내, 백업 복구를 확인합니다.
현재 자동 검사는 데이터 검증·이미지 주소 검사 및 자바스크립트 문법 중심입니다. 실제 Cloudflare 로그인·R2 쓰기·배포 동작은 계정 연결 후 검증해야 합니다.
